# Public Procurement Dashboard

조달청 특정품목 조달 내역 CSV를 브라우저에서 업로드해 안내전광판, 기상전광판, 교통정보전광판 분야별 업체 계약 현황을 확인하는 정적 대시보드입니다.

## 기능

- UTF-16 조달청 CSV/TSV 파일 업로드 및 브라우저 내 분석
- 분야별 필터: 안내전광판, 기상전광판, 교통정보전광판
- 지표 전환: 계약금액, 계약건수
- 기간 필터 및 업체명 검색
- 업체별 트리맵 대시보드
- 업체 클릭 시 계약 상세 목록 표시

## 로컬 실행

```powershell
node server.mjs
```

브라우저에서 `http://localhost:5174`를 엽니다.

## GitHub Pages

정적 파일만 사용하므로 GitHub Pages에서 바로 호스팅할 수 있습니다. 저장소 루트를 Pages 소스로 지정하면 됩니다.
